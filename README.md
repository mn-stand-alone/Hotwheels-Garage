# 犇犇的车库

原生 HTML / CSS / JavaScript 的车辆收藏游戏，包含自动驾驶的 3D 人机对战。

## 本地运行

推荐双击项目目录的 `start-game.cmd`，它会启动本地服务并优先用 Chrome 播放完整片头，点击进入后打开首页。游玩时保持启动窗口开启；首次运行需要安装 Python 3。启动器自动检测 `py -3` / `python`；HTML、JavaScript 与 CSS 请求会重新验证缓存，以便加载更新。更新启动器后，如旧服务窗口仍在运行，请关闭旧窗口再重新启动。

不要从 Chrome 的“打开文件”功能打开 HTML，应该打开 `http://127.0.0.1:8765/home.html`。如果已在文件地址下收集车辆，先在原地址的首页导出进度，再到本地网址导入；不同浏览器的存档也互相独立。

也可以在项目目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/home.html>；对战页为 <http://127.0.0.1:8765/battle.html>。
请保持同一域名和端口使用，以读取原有浏览器存档。`localhost` 和 `127.0.0.1` 是不同存档来源。
不支持直接双击 HTML 文件运行对战模块：ES modules 与多标签页锁需要 HTTP 安全本地来源。
3D 渲染需要支持 WebGL 2 的浏览器。依赖本地提供，无需联网或构建步骤。

## 对战玩法

- 每天每个场景限 1 次，三个场景合计 3 次，与抽卡次数独立；正式发车才扣次，弃赛不返还。暂停、刷新和继续比赛不重复扣次。
- 一辆玩家赛车和两辆 AI 自动行驶，比赛中只需点击氮气或按空格。
- 玩家氮气无限次，每次持续 2.5 秒，结束后恢复 1.25 秒；AI 氮气无限次，每次 2.5 秒，恢复时间与操控属性正相关。不叠加、不自动连发。旧版未完成比赛沿用旧规则。
- 三条海岛赛道：滨海天际线（2900 米高速 S 弯）、恐龙丛林（2500 米连续山路）、海上巨环（2600 米双回环）。参考 FH3: Hot Wheels，采用程序化 3D 改编，详见 [场景参考](assets/battle/场景参考.md)。
- 每场最多 150 秒；按冲线时间排名，未冲线的车辆按进度排名，相同成绩并列。
- 刷新、切换后台后可继续同一场比赛，不重复扣次。
- 首次夺冠获得对应赛道徽章；记录最近 30 场和个人最佳。

## 开发与验证

```powershell
node tests/battle.test.cjs
node tools/audit-battle.cjs
```

规则测试不访问真实浏览器存档。第二个命令生成 `assets/battle/vehicle-review.json`，列出按名称规则估算的待校对车型。
[对战模块计划书](docs/对战模块计划书.md) 是设计依据；[对战模块验收记录](docs/对战模块验收记录.md) 记录实现边界与测试结果。

比赛逻辑固定为 60 Hz，与渲染分离。`battle-engine.js` 负责模拟，`battle-ai.js` 负责 AI 氮气，`battle-tracks.js` 负责路线，`battle-scene.js` 负责 Three.js 场景。
自动驾驶是受约束的街机运动模型：车辆沿赛道行驶，在丛林赛道近距离接触时处理推挤，回环保持贴合，避免永久卡死；不是完整刚体赛车模拟。

车型按名称分类为八类车身，性能由车型基础值与名称固定差异构成；未知创意车型采用概念车设定。数值为游戏估算，稀有度不参与计算，同车型跨批次共享性能。
三维车身是八类程序化展示模板，不是 694 辆真实车型的独立精确模型。

Three.js 0.180.0 使用 MIT 许可；完整许可位于 `vendor/three/LICENSE`。其他新场景资源为项目内程序化生成，说明见 `assets/battle/README.md`。

## 游戏声音

所有正式页面已接入背景音乐与音效，右下角“声音设置”分别控制音乐和音效。首次点击后启用，后台自动停止。详情见 [声音系统说明](docs/声音系统说明.md)，试听页为 `tests/audio-preview.html`。

## 文件夹导航

| 位置 | 用途 |
| --- | --- |
| `index.html`、`home.html`、`draw.html`、`garage.html`、`battle.html` | 游戏入口页面 |
| `start-game.cmd` | Windows 本地启动入口 |
| `js/`、`css/` | 游戏逻辑与样式 |
| `images/`、`thumbs/`、`fonts/` | 车卡原图、缩略图和字体 |
| `assets/` | 游戏使用的音乐、场景说明与车型校对数据 |
| `vendor/` | 本地 Three.js 运行依赖及许可证 |
| `docs/` | 开发计划、规则说明和历史验收记录 |
| `tests/` | 自动测试与不消耗次数的试听、试跑页面 |
| `tools/` | 启动服务、音乐切分和车型审计脚本 |
| `.cache/audio-tools/` | 音乐切分工具依赖，重新制作音乐时使用 |
| `test-results/` | 临时验收输出，已忽略版本控制 |

根目录原始 `.m4a` 是后续音乐切分的源素材，游戏播放使用 `assets/audio/` 中的片段。原素材保留在原位置，方便切分脚本继续使用。

最新规则见 [AI 对战规则](docs/AI对战规则.md) 和 [赛道扩展与检查](docs/赛道扩展与检查.md)。整理记录见 [项目结构与清理记录](docs/项目结构与清理记录.md)。

### 收藏与对战选车

抽卡结果（单抽、连抽）和车库卡牌/详情均可点击星标收藏。车库可筛选“★ 已收藏”，取消收藏不会删除车辆。对战仅允许收藏车辆发车；没有收藏时请先去车库添加，旧存档不会自动收藏全部车辆。收藏随备份导入/导出。

每日每张地图限一次，三张地图合计三次，发车扣次，弃赛不返还，继续比赛不重复扣次。旧五次制按可恢复的当日地图记录去重迁移；无法恢复的已用次数保守保留，但最多三次。跨天重置。
