## 三项属性影响增强（版本 6，最新覆盖规则）

本节优先于下方历史公式，玩家、AI 和匹配估算共用。

| 参数 | 新公式 | 属性 60 → 100 的表现 |
|---|---|---|
| 基础速度上限 | 55.6 + (T − 80) × 0.55 m/s | 160.56 → 239.76 km/h |
| 基础加速度 | 14.4 + (A − 80) × 0.24 m/s² | 9.6 → 19.2 m/s² |
| 普通地图弯道系数 | 1 − C × (100 − H) / 100 | 丛林 C=0.55 时保留 78% → 100% 速度 |
| 海上巨环弯道系数 | max(0.35, 1 − C × (100 − H) / 65) | 回环 C=1 时保留约 38.5% → 100% 速度 |

保持 80 分速度和加速的基准值不变，增强高低分差距。氮气、重量、总分、采样点和每日次数保持原规则。旧版本 5 比赛保留进度和氮气计时，恢复后应用版本 6 公式；个人最佳按新版单独记录。

## 1. 属性定义

属性变量：速度 T、加速 A、操控 H、氮气 N、重量 W。属性为游戏评分，不是物理单位。


| 项目 | 当前设置 | 目标设置 |
|---|---|---|
| 属性范围 | 每项 0–100 | |
| 属性总和 | 按稀有度 360/390/420/450 | |
| 同名车型跨批次 | 共享相同性能 | |

## 2. 属性对应关系

| 属性 | 影响参数 | 当前作用 | 目标设置 |
|---|---|---|---|
| 速度 | 基础速度上限 | 越高越快 | |
| 加速 | 基础加速度 | 越高提速越快 | |
| 操控 | 弯道速度系数 | 越高弯道速度损失越小 | |
| 操控 | 横向车道跟随 | 越高越快回归目标车道 | |
| 操控 | AI 氮气恢复 | 越高恢复时间越长；不影响玩家 | |
| 氮气 | 氮气加速的恢复时间 | 越高恢复时间越短
| 氮气 | 氮气加速的持续时间 | 越高持续时间越长
| 稳定 | 碰撞降速 | 越高损失越小 | |


## 3. 速度与加速度公式

速度单位 m/s，乘 3.6 为 km/h；加速度单位 m/s²。C 为当前路段曲率系数，B 为当前路段氮气系数。二者是游戏配置值，不是直接读取 3D 道路几何曲率。

| 游戏参数 | 当前公式/数值 | 目标设置 |
| 基础速度上限 V | 34 + T × 0.27 | |
| 基础加速度 a | 6 + A × 0.105  | |
| 滨海天际线、恐龙丛林弯道系数 K | 1 − C × (100 − H) ÷ 400 | |
| 海上巨环弯道系数 K | max(0.35, 1 − C × (100 − H) ÷ 80) | |
| 非氮气速度上限 | V × K | |
| 氮气速度上限 | V × K + 20 × B | |
| 氮气期间加速度 | a × 1.6 | |
| 模拟步长 dt | 1/60 秒 | |
逐步速度更新：`新速度 = max(0, 当前速度 + max(−20 × dt, min(当前加速度 × dt, 当前速度上限 − 当前速度)))`。氮气不会立即将速度提升至上限。

## 4. 氮气参数

恢复计时从氮气持续时间结束后开始，不能叠加释放。


| 参数 | 玩家当前设置 | AI 当前设置 | 玩家目标设置 | AI 目标设置 |
| 次数 | 无限 | 无限 | | |
| 持续时间 | 2.5 秒（150 帧） | 2.5 秒（150 帧） | | |
| 恢复时间 | 根据AI选择车辆计算，计算公式相同 | round((1 + H × 0.025) × 60) / 60 秒 | | |
| 速度上限增量 | 20 × B m/s | 20 × B m/s | | |
| 加速度倍率 | 1.6 | 1.6 | | |

例如 AI 操控为 70 时，恢复时间为 2.75 秒；与玩家相比存在恢复时间差异。

## 6. 横向运动与碰撞


| 参数 | 当前设置 | 目标设置 |
|---|---|---|
| 三车目标车道 | 玩家 −3.5、AI 1 为 0、AI 2 为 +3.5 米；固定车道 | |
| 每帧车道跟随 | 当前车道 += (目标车道 − 当前车道) × min(1, dt × (1.4 + H/40)) | |
| 横向位置限制 | −4.8 至 +4.8 米 | |
| 启用碰撞的地图 | 都启用 | |
| 碰撞判定 | 路程差 < 6 米，世界坐标差分别满足：y < 2.5、z < 4.2、x < 2.05 米；双方未冲线 | |
| 同一对车辆碰撞间隔 | 100 帧，约 1.67 秒 | |
| 碰撞降速比例 L | min(0.27, 0.08 × 对方 W / 自身 W + (100 − 自身 S) × 0.001) | |
| 碰撞后速度 | 当前速度 × (1 − L) | |
| 碰撞横向位移幅度 | 0.65 × 对方 W / 自身 W 米，再限制到车道边界 | |
| 碰撞表现标记时长 | 28 帧，约 0.47 秒 | |

## AI 匹配档次上限（2026-11-02）

新匹配的两位 AI 稀有度均不得高于玩家：普通只匹配普通；稀有匹配普通或稀有；史诗匹配普通、稀有或史诗；传说可匹配全部档次。在此限制内按预计完赛能力选择接近玩家、车型不同的对手。正在进行的比赛不在中途更换对手。
