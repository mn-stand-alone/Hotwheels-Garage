# 收藏与每日对战更新

- 抽卡单抽、连抽结果及车库卡牌/详情提供收藏和取消收藏按钮。
- 车库增加已收藏筛选和收藏计数；取消收藏不删除已获得车辆。
- 对战只列出收藏车辆，并在发车时再次校验。没有收藏时提示前往车库。
- 收藏数据随备份导入导出，旧存档默认未收藏，不自动选择车辆。
- 每天每地图一次，三个地图合计三次。正式发车扣次，弃赛不退次，恢复比赛不重复扣次。
- 旧五次制存档按可恢复的当日地图记录去重；无法恢复的已用次数保守保留，最多三次。迁移同步压缩旧比赛 ID 列表，保证后续发车仍可保存。
- 更新页面资源版本，避免复用旧脚本。

## 验证

- favorites.test.cjs：收藏持久化、导入校验、非收藏发车拒绝、取消收藏后继续已开始比赛、旧存档迁移后继续发车及跨天重置。
- battle.test.cjs：每日每地图限次、总额三次、恢复和重复结算不扣次、旧版兼容等规则回归。
- 上次隔离端口浏览器验收：收藏筛选仅显示选中的车辆，对战仅列出该收藏车辆，三张地图显示每日一次，顶部显示 3 / 3。未消耗正式游戏次数。

使用：刷新页面后，先在车库点击“☆ 加入收藏”，再进入对战选车。
