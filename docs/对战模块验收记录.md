# 对战模块首版验收记录

开发及主要测试：2026-10-22；交付复核：2026-10-23。设计依据为《对战模块计划书.md》。

## 已交付

- 三车自动竞速：玩家一辆、AI 两辆。赛中只有氮气操作，支持鼠标和空格。
- 每场 2 次、每次 2.5 秒氮气，不允许生效期间叠加或长按连发。
- 三条实时 3D 赛道：直线竞速、岔路碰撞、立体回环。
- 程序化五类车身、车轮、尾焰、碰撞反馈、跟随镜头和回环全景镜头。
- 固定 60 Hz 模拟、种子与输入记录、属性权重、自动路线、碰撞损失及排名。
- 每日 5 次，正式发车扣次；刷新恢复、后台暂停和继续不重复扣次。
- 战绩、首胜徽章、个人最佳、最近 30 场记录、弃赛与导入导出兼容。
- 首页战报、导航入口、图鉴性能与“使用此车对战”入口。
- 多标签页使用 Web Locks 排他锁；WebGL 中断回调暂停比赛。
- 画质档位、减少动态效果、运行帧率提示和资源失败提示。

## 自动测试

命令：`node tests/battle.test.cjs`。结果：**16 项通过**。

覆盖范围：

1. 694 张卡均有合法属性与车身模板，五种属性总预算相同。
2. 同名车型跨批次性能一致。
3. 24 辆代表车在三条赛道、玩家不使用氮气时全部于 60 秒内完赛。
4. 相同输入可复现比赛，快照恢复后最终状态一致。
5. 氮气次数、生效时长与叠加限制，氮气可改善成绩。
6. 回环入口与出口连续，顶部车辆姿态倒转。
7. 碰撞发生且重车比例速度损失更低。
8. 并列及 60 秒超时按规则排名。
9. 每日五次、快照及重复结算不重复扣次，不改变抽卡次数。
10. 跨日继续旧比赛不消耗新一天次数。
11. 旧存档兼容、无效导入不覆盖已有进度。
12. 新存档往返导入、进行中的比赛阻止导入覆盖。
13. 存储失败时保留当前会话数据。
14. 首胜徽章不重复发放、个人最佳不被较慢成绩覆盖。
15. 损坏对战数据不会被静默重置，可用有效备份恢复。
16. 三种赛道的基准最优定位不同。

另外已完成所有项目 JavaScript 的语法检查，以及 HTML 引用本地资源存在性检查。

## 数值基线

同一氮气输入方案（第 500、1400 模拟步），每个定位、每条赛道运行 20 个种子，玩家平均完赛秒数：

| 定位 | 直线 | 岔路碰撞 | 回环 |
|---|---:|---:|---:|
| 极速型 | 25.955 | 26.405 | 27.240 |
| 加速型 | 27.128 | 27.247 | 27.970 |
| 操控型 | 28.279 | 27.052 | 26.214 |
| 均衡型 | 27.854 | 26.601 | 28.004 |
| 冲撞型 | 29.559 | 26.058 | 30.898 |

这是首版平衡基线，不能证明所有车型、种子、操作时机下已达到最终平衡。后续可根据试玩反馈继续调参。

## 浏览器实测

使用桌面内置浏览器，1280 × 720 视口，标准画质；测试使用 `http://localhost:8765` 的独立存档，没有消耗用户原 `http://127.0.0.1:8765` 存档的次数。

- 完成 5 场比赛，覆盖三条赛道；第 6 次发车被禁用，页面显示剩余 0 / 5。
- 鼠标释放第一发氮气后刷新，恢复原赛况且次数不重复扣减；空格正常释放第二发。
- 回环在不使用玩家氮气时正常完赛，实测体验车成绩为 30.113 秒。
- 岔路比赛记录了真实交汇碰撞、降速比例与结算事件。
- 修正回环支柱遮挡，使用侧面全景镜头观察倒置车辆与完整回环。
- 3D 页面帧率观测约 60 FPS；浏览器测试页 180 帧采样结果为 60 FPS。此结果仅代表当前设备与测试视口，不是跨设备性能保证。
- 排他锁测试：第二个并发锁请求被拒绝，释放后能重新获取。
- 通过 `WEBGL_lose_context` 扩展触发中断和恢复，两个回调均通过，恢复后重新渲染。
- 五场对战后首页抽卡仍为 10 次；另执行一次抽卡，变为 9 次、收藏增加到 1，图鉴与对战入口正常。
- 从图鉴点击“使用此车对战”后，赛场正确预选该车辆。
- 浏览器检查未发现 JavaScript error 日志。

开发辅助页：`tests/browser-checks.html`，用于回环 / 岔路静态场景、锁与 WebGL 回调检查，不读写收藏存档。

## 实现边界与后续工作

- 使用受约束的街机运动与碰撞模型，不是完整刚体物理仿真。
- 全部 694 张卡可以参与对战。其中 72 张按精确车型名称配置定位，622 张按计划使用带提示的均衡模板，等待进一步人工校对。清单位于 `assets/battle/vehicle-review.json`，可通过 `node tools/audit-battle.cjs` 重新生成。
- 3D 使用五种程序化展示模板，未制作 694 个精确真实车型模型。
- 首版为本地人机，未接入多人联机、账号或排行榜。浏览器本地次数和战绩不是防作弊数据。
- 电脑端为首版目标。低端设备、触屏设备和 WebGL 完全不可用设备没有完成专项实机测试；已有失败提示与流畅档位。
- 本次验证覆盖 WebGL 恢复回调和存档恢复各自路径，未穷举操作系统、驱动崩溃等全部异常组合。
