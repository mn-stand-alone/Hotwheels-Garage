# 本地歌单场景切分

来源为用户指定的项目根目录 m4a，原文件保留。切分依据静音边界与波形能量；以下名称是场景标签，不是原曲名。

| 场景 | 原素材时间段 | 导出文件 | 时长 |
| --- | --- | --- | --- |
| 首页、抽卡、对战大厅、结算 | 03:34–06:04 | home.m4a | 2:30 |
| 收藏车库 | 09:21–12:21 | garage.m4a | 3:00 |
| 滨海天际线比赛 | 13:54–15:54 | sprint.m4a | 2:00 |
| 恐龙丛林比赛 | 19:29–21:29 | fork.m4a | 2:00 |
| 海上巨环比赛 | 28:32–30:32 | loop.m4a | 2:00 |

五段总计约 14.4 MB。导出为 44.1 kHz 双声道 AAC / M4A，160 kbps；响度处理目标 -18 LUFS、峰值目标 -2 dBTP；每段开头 1.2 秒淡入、结尾 2 秒淡出。循环是淡出后重新淡入，不是节拍无缝拼接。

游戏按场景加载单个音频文件，独立于引擎、氮气和按钮音效。音乐开关或切换后台会暂停播放，再次启用会继续当前片段。切换场景换用对应文件；跨 HTML 页面重新开始播放。

`manifest.json` 记录原文件 SHA256、时间点与输出文件。重新切分执行 `python tools/split-game-music.py`，工具依赖项目缓存 `.cache/audio-tools` 中的 imageio-ffmpeg。正常游玩只需要导出的五个文件，不需要安装音频工具。
